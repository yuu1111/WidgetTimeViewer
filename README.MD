# WidgetTimeViewer

[English](README-EN.MD)

[Elin](https://store.steampowered.com/app/2135150/Elin/) 用のBepInEx Mod

画面左上の表示情報に時間表示を追加します。

---

## 機能

- ウィジェットに年月日と時刻を表示
- 日本語環境では「○時○分」形式、それ以外では「HH:MM」形式で表示

## インストール

Steam Workshopから [WidgetTimeViewer](https://steamcommunity.com/sharedfiles/filedetails/?id=3352893889) をサブスクライブ
